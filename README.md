# magento2-checkout

The new Monta Checkout module for modern Magento webshops. Connects your webshop to Monta for shipping and pickup
options.

## Configuration

API credentials can be configured and tested under:
`Stores > Configuration > Sales > Shipping Settings > Monta API`

The Monta shipping method can be configured under:
`Stores > Configuration > Sales > Delivery Methods > Monta`.

#### API credentials

To use this module you need API credentials for the Monta API. These can be found in your account on the Monta Portal.

#### Google API

A valid Google Maps API key is needed to display pickup points on a map in checkout.
Your key can be created here:
[https://developers.google.com/maps/js/get-api-key](https://developers.google.com/maps/documentation/javascript/get-api-key)
